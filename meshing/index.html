    Meshing

    Mesh quality directly affects the accuracy of your results. The goal is to use the right element type, refine where it matters, and keep computational cost reasonable.

    What element type should I use?

    Use quad or hex elements whenever possible. They are more accurate than triangles and tetrahedra.

    Structure type Preferred element Avoid
    Thin-walled shells S4R (quad shell) S3R (tri shell)
    Solid / thick geometry C3D8R (hex/brick) C3D4 (tet)

    How to assign element shape in Abaqus:

    1. Go to the Mesh Module
    2. Click Assign Mesh Controls
    3. Select all your parts and click Done
    4. Choose Quad or Quad-dominated and Structured, then click OK
    5. Your parts should turn green — this means a structured quad mesh is possible

    If Abaqus shows an error (geometry too complex for structured mesh), try Sweep or Free > Medial Axis instead.

    How do I choose an appropriate mesh size?

    There is no single correct answer, but these principles will guide you:

    Start coarser than you think you need. Run the analysis first, then refine. Jumping straight to a very fine mesh wastes time and makes it harder to troubleshoot problems.

    Refine where gradients are steep. High stress gradients occur at: - Stress concentrations (holes, corners, notches, fillets) - Load introduction points and boundary condition locations - Interfaces between dissimilar materials - Regions you identified as critical in your objectives

    Match element size to feature size. Put at least 3–4 elements across any geometric feature you want to capture accurately. A fillet with only one element across it will not give reliable stress results.

    Do a convergence study. Run the analysis at your initial mesh, then refine by roughly halving the element size in the critical region and re-run. If the key quantity (stress, deflection) changes by more than ~5%, refine further. See Modeling Approach for more detail.

    Rule of thumb: Start with an element size of roughly 1/20 to 1/50 of the smallest critical dimension of your structure. Refine locally from there.

    Why is partitioning important?

    Partitioning means splitting a part into smaller regions — not physically, but as geometry that Abaqus uses to control meshing. It is one of the most important meshing tools because:

    • It lets you control element size independently in different regions (fine near stress concentrations, coarse far away)
    • It makes structured (quad/hex) meshing possible on geometry that would otherwise require unstructured tets
    • It lets you align element edges with expected stress flow directions, improving accuracy
    • It creates boundaries where you can apply different element types or section properties

    If your model turns yellow or orange in Abaqus (indicating a free mesh of tets is required), partitioning is usually the fix.

    How do I partition my geometry?

    Abaqus offers several partitioning methods depending on what you are cutting:

    Partition Face — Sketch Draw a line or curve on a face to split it. This is the most flexible method and works well for adding cut lines to planar surfaces.

    1. In the Mesh Module (or Part Module), go to Tools > Partition
    2. Select Face, then Sketch
    3. Draw the partition line and click Done

    Partition Cell — Use Datum Plane Cuts a 3D solid with a flat plane. Useful for splitting a box into regions with different mesh densities.

    1. First create a datum plane: Tools > Datum > Plane
    2. Then Tools > Partition > Cell > Use Datum Plane and select the plane

    Partition Cell — Extend Face Extends an existing face of the part to cut through the interior. Fast and useful when a natural surface already defines where you want to cut.

    Partition Edge — Enter Parameter Splits an edge at a fractional position along its length. Useful for adding a seed point at a specific location.

    General tip: Add a transition region between your fine mesh area and the coarse mesh area. Use biased seeds on the edges in the transition zone so element size changes gradually. Abrupt size jumps create poorly shaped elements with high aspect ratios that reduce accuracy.

    How do I refine the mesh locally?

    1. Partition your geometry to isolate the region that needs refinement
    2. In the Mesh Module, click Seed > Edges and select the edges of the fine region
    3. Set a smaller element size for those edges
    4. Use Seed > Edges on the transition edges and enable Bias to grade gradually from fine to coarse
    5. Re-mesh and check quality with Mesh > Verify

    How do I check mesh quality?

    1. In the Mesh Module, click Mesh > Verify
    2. Box-select your entire assembly (or individual parts), then click Done
    3. Set the parameters you want to check (aspect ratio, angle limits, etc.) and click Highlight
    4. Elements highlighted in the viewport are considered poor quality — refine or repartition those regions

    General mesh tips

    • Avoid elements with very large aspect ratios (much longer in one direction than another)
    • Shell models should have element sizes similar in both in-plane directions
    • For composite laminates, the element size in-plane is more critical than through-thickness since shells handle the thickness direction analytically
    • After any mesh change, re-run and compare key outputs to confirm convergence
