    Tutorial 1: Modal Analysis of a Cantilever Uniform Wing

    Overview

    This tutorial walks through the analytical prediction of natural frequencies for a uniform cantilever wing modeled as a thin-walled beam. We treat the wing as having a constant cross-section along its span — the uniform assumption — which lets us derive exact (or nearly exact) closed-form expressions for each vibration mode.

    We work through three topics in sequence:

    1. Bending natural frequencies — flap and chord directions
    2. Torsional natural frequencies
    3. Cross-section properties — how to compute the geometric quantities the frequency equations need

    Finally, we compare our analytical predictions against a finite element solution in Abaqus.

    Part 1: Natural Frequencies of a Cantilever Beam

    Before worrying about the cross-section, it helps to understand the frequency equations themselves. Both bending and torsion lead to a vibrating distributed system — a continuous beam — and the frequencies come from satisfying the governing PDE plus the boundary conditions at the root and tip.

    1.1 Bending Vibration

    The governing equation

    The Euler-Bernoulli beam equation for free, undamped bending vibration is:

    $$EI \frac{\partial^4 w}{\partial x^4} + \rho A \frac{\partial^2 w}{\partial t^2} = 0$$

    where:

    Symbol Meaning
    $E$ Young's modulus
    $I$ Second moment of area about the bending axis
    $\rho$ Mass density
    $A$ Cross-sectional area
    $w(x,t)$ Transverse displacement
    $x$ Spanwise coordinate

    The equation is fourth order in space, which is the signature of a bending wave — curvature couples to moment, and moment couples to shear, adding two spatial derivatives each time.

    Assumed solution and separation of variables

    We assume harmonic motion:

    $$w(x,t) = W(x)\sin(\omega t)$$

    Substituting gives an ODE for the mode shape $W(x)$:

    $$W^{(4)}(x) - \beta^4 W(x) = 0, \qquad \beta^4 = \frac{\rho A \omega^2}{EI}$$

    The general solution is:

    $$W(x) = C_1 \sin(\beta x) + C_2 \cos(\beta x) + C_3 \sinh(\beta x) + C_4 \cosh(\beta x)$$

    Cantilever boundary conditions

    A cantilever is clamped at the root ($x = 0$) and free at the tip ($x = L$):

    $$W(0) = 0 \quad \text{(no displacement at root)}$$ $$W'(0) = 0 \quad \text{(no slope at root)}$$ $$W''(L) = 0 \quad \text{(zero bending moment at tip)}$$ $$W'''(L) = 0 \quad \text{(zero shear force at tip)}$$

    Applying all four conditions reduces the problem to a transcendental characteristic equation:

    $$\cos(\beta_n L)\cosh(\beta_n L) + 1 = 0$$

    This equation has no closed-form solution, so we use pre-computed roots:

    Mode $n$ $\beta_n L$
    1 1.87510
    2 4.69409
    3 7.85476

    Note: For higher modes ($n \geq 4$), the asymptotic approximation $\beta_n L \approx (n - \tfrac{1}{2})\pi$ is accurate to better than 0.1%.

    From $\beta_n$ to frequency

    Once $\beta_n L$ is known, the natural frequency for mode $n$ is:

    $$\boxed{\omega_n = \frac{(\beta_n L)^2}{L^2} \sqrt{\frac{EI}{\rho A}}, \qquad f_n = \frac{\omega_n}{2\pi}}$$

    A useful way to read this expression:

    • $(\beta_n L)^2 / L^2$ encodes the mode shape geometry — it grows quickly with mode number
    • $\sqrt{EI / \rho A}$ is a material and geometry stiffness-to-inertia ratio — stiffer or lighter sections vibrate faster

    Flap vs. chord bending

    The formula above applies identically for flap bending (out-of-plane, resisted by $I_{xx}$) and chord bending (in-plane, resisted by $I_{yy}$) — only the moment of inertia changes. Because $I_{yy} \gg I_{xx}$ for a flat wing, chord frequencies are always substantially higher than flap frequencies.

    1.2 Torsional Vibration

    The governing equation

    Free torsional vibration of a uniform shaft is governed by:

    $$GJ \frac{\partial^2 \theta}{\partial x^2} = \rho I_p \frac{\partial^2 \theta}{\partial t^2}$$

    where:

    Symbol Meaning
    $G$ Shear modulus
    $J$ Torsional constant (Bredt-Batho for thin-walled closed sections)
    $\rho$ Mass density
    $I_p$ Polar moment of area ($= I_{xx} + I_{yy}$)
    $\theta(x,t)$ Twist angle

    This is a wave equation — second order in both space and time. The lower order (compared to bending) has an important consequence: the torsional mode structure is simpler and the eigenvalues are exact.

    Cantilever boundary conditions

    $$\theta(0) = 0 \quad \text{(no twist at the fixed root)}$$ $$\left.\frac{\partial \theta}{\partial x}\right|_{x=L} = 0 \quad \text{(zero torque / free warping at the tip)}$$

    These two conditions yield a closed-form eigenvalue — no transcendental solve required:

    $$\beta_n L = \frac{(2n-1)\pi}{2}, \quad n = 1, 2, 3, \ldots$$

    Torsional natural frequencies

    $$\boxed{\omega_n = \frac{(2n-1)\pi}{2L} \sqrt{\frac{GJ}{\rho I_p}}, \qquad f_n = \frac{\omega_n}{2\pi}}$$

    The torsional mode ratio is exactly $1 : 3 : 5 : 7 : \ldots$ — the modes are harmonically related, unlike bending modes (which grow roughly as $1 : 6.3 : 17.5$). This difference traces directly back to the order of the governing equation.

    Physical intuition: A guitar string (tension wave, 2nd order PDE) produces harmonically spaced overtones. A cantilever beam (bending wave, 4th order PDE) does not. Torsion behaves like a string, bending does not.

    Part 2: Cross-Section Properties

    The frequency equations in Part 1 require five section properties: $A$, $I_{xx}$, $I_{yy}$, $J$, and $I_p$. This section explains how to compute each one for a thin-walled airfoil section composed of skin panels and spar webs.

    The fundamental idea is to represent the cross-section as a collection of thin-wall segments. Each segment has:

    • Arc length $ds$
    • Thickness $t$
    • Midpoint position $(y_m, z_m)$

    All section properties are built from weighted integrals along these segments.

    Axis convention used throughout: $x$ runs along the span, $y$ runs along the chord, and $z$ runs in the flap (thickness) direction.

    2.1 Structural Area

    The simplest property. For a thin-wall segment, area is just thickness times arc length summed around the entire section:

    $$A = \oint t \, ds \approx \sum_i t_i \, \Delta s_i$$

    This includes all skin segments and both spar webs.

    2.2 Centroid

    The centroid is the area-weighted average position of the material:

    $$\bar{y} = \frac{\oint t \cdot y_m \, ds}{A}, \qquad \bar{z} = \frac{\oint t \cdot z_m \, ds}{A}$$

    Getting the centroid right matters because $I_{xx}$ and $I_{yy}$ must always be computed about the centroidal axes — not an arbitrary reference point.

    2.3 Second Moments of Area

    These measure how far the material is distributed from each neutral axis. More material far from the axis means a stiffer, higher-frequency response in that direction.

    $$I_{xx} = \oint t \, (z_m - \bar{z})^2 \, ds \qquad \text{(resists flap bending)}$$

    $$I_{yy} = \oint t \, (y_m - \bar{y})^2 \, ds \qquad \text{(resists chord bending)}$$

    The subtraction of $\bar{z}$ and $\bar{y}$ inside each integral applies the parallel axis theorem automatically — it shifts every segment's contribution to the centroidal axis.

    Physical note on spar webs: The front and rear spar webs sit near $z = 0$ (the neutral axis for flap bending), so they contribute almost nothing to $I_{xx}$. But they sit at $y = y_\text{spar}$, well away from the chordwise centroid, so they contribute significantly to $I_{yy}$. This is why chord stiffness is so much higher than flap stiffness in a typical wing.

    2.4 Polar Moment of Area

    The polar moment is simply the sum of the two bending moments:

    $$I_p = I_{xx} + I_{yy}$$

    It appears in the torsion frequency equation as the rotational inertia of the cross-section — how much the section resists angular acceleration about the spanwise axis.

    2.5 Torsional Constant — Bredt-Batho Formula

    For a closed thin-wall section, shear flow under torsion is uniform around the cell. The Bredt-Batho formula gives:

    $$J = \frac{4 A_\text{enc}^2}{\displaystyle\oint \frac{ds}{t}}$$

    where $A_\text{enc}$ is the enclosed area of the cell and $\oint ds/t$ is the perimeter integral weighted by inverse thickness.

    Enclosed area — shoelace formula

    Given discrete boundary points $(y_i, z_i)$ around the cell:

    $$A_\text{enc} = \frac{1}{2} \left| \sum_i \bigl(y_i z_{i+1} - y_{i+1} z_i\bigr) \right|$$

    Which cell to use?

    This is a modeling choice with real consequences:

    • Full airfoil cell: integrate around the entire closed skin contour. Uses the full aerodynamic shape and maximizes $A_\text{enc}$.
    • Inter-spar box cell: integrate only around the rectangle bounded by the two spar webs and the upper and lower skin panels between them. More conservative; this is the cell that actually carries the bulk of the torsional shear flow in a typical wing box.

    The $A_\text{enc}^2$ dependence means a larger enclosed area makes the section much stiffer in torsion — this is why hollow sections are structurally efficient. The full-skin approach will overestimate $J$ if the nose and tail regions are structurally negligible.

    A few things to look for when comparing analytical and FE predictions:

    Sources of discrepancy:

    • The analytical model assumes a perfectly uniform section along the full span. The FE model may capture tapering, root boundary effects, or local reinforcements.
    • The boundary condition at the root matters more than it might seem. A rigid clamp in the analytical model vs. a constrained set of nodes in Abaqus can shift lower-mode frequencies noticeably.
    • Warping stiffness is neglected in the classical torsion formula but is included (to varying degrees) in beam element formulations. This typically raises torsional frequencies slightly relative to the Bredt-Batho prediction.
    • The closed-skin vs. box-cell choice for $J$ can produce meaningful differences in torsional frequency; make sure both models are using a consistent assumption.

    Appendix: MATLAB Implementation

    The script wing_frequency_4.m implements everything described above. The code is organized into three functions:

    • section_props — builds the segment arrays and computes $A$, $I_{xx}$, $I_{yy}$, $J$, $I_p$ for the airfoil cross-section
    • bending_modes — applies the cantilever bending eigenvalue equation to return $f_n$ for $n = 1 \ldots N$
    • torsion_modes — applies the closed-form torsional eigenvalue to return $f_n$

    The airfoil shape is defined by tabulated $(y, z)$ coordinates for the upper and lower surfaces, scaled by the chord length. Spar web heights are obtained by interpolating those tables at the front and rear spar chord locations.

    %% Key parameters
E     = 10e6;       % psi
NU    = 0.33;
G     = E / (2*(1+NU));
rho_w = 0.1;        % lb/in^3 (weight density)
rho   = rho_w / 386.4;  % slug/in^3 (mass density)

CHORD  = 20.0;      % in
SPAN   = 84.0;      % in
SKIN_T = 0.040;     % in
SPAR_T = 0.060;     % in
YSPAR1 = 5.0;       % front spar at 25% chord
YSPAR2 = 14.0;      % rear spar  at 70% chord

    Note on units: The weight density rho_w is in lb/in³. Dividing by $g = 386.4$ in/s² converts to mass density in lb·s²/in⁴ (slugs/in³), which is what the frequency equations require when forces are in pounds and lengths in inches.
