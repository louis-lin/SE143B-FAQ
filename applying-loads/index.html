    Applying Loads

    This page covers how to apply different types of mechanical loads in Abaqus, including the aerodynamic pressure and surface traction loads used in aerospace structural analysis.

    Pressure vs. Surface Traction — what is the difference?

    Pressure is, by definition, always applied normal to the surface. Abaqus handles the direction automatically — you only specify the magnitude. A positive value pushes into the surface (compressive); a negative value pulls away (suction).

    Surface Traction is a more general load that acts in any direction you specify — it is not constrained to be normal to the surface. A surface traction has two components:

    • TRNOR — the component normal to the surface
    • TRSHR — the component tangential (shear) to the surface

    For aerodynamic analysis, pressure is the appropriate load type because aerodynamic pressure acts by definition perpendicular to the surface. Surface traction is used when a load has a known in-plane component (e.g., distributed friction, follower forces).

    How do I apply aerodynamic pressure?

    Aerodynamic pressure (from CFD, panel methods, or hand calculations) acts normal to the surface and is applied directly as a Pressure load in Abaqus.

    Steps:

    1. In the Load Module, click Create Load
    2. Select Mechanical > Pressure and click Continue
    3. Select the aerodynamic surface faces
    4. Enter the pressure magnitude:
    5. Uniform load: enter a single value
    6. Spatially varying load: create an Analytical Field first (see below), then set Distribution to that field
    7. Abaqus automatically applies the load perpendicular to the surface — no direction vector needed

    Sign convention: positive pressure acts opposite to the surface outward normal (compressive into the surface). Use negative values for suction regions.

    For a spatially varying pressure (e.g., from Cp distribution):

    1. In the Load Module, go to Tools > Analytical Field > Create
    2. Select Expression field and write your expression using global coordinates (X, Y, Z)
    3. When creating the pressure load, set Distribution to your analytical field

    How do I apply a surface traction?

    Use a surface traction when your load has a fixed global direction rather than following the surface normal — for example, a shear force distributed over a face.

    1. In the Load Module, click Create Load
    2. Select Mechanical > Surface Traction
    3. Choose General traction
    4. Specify the direction vector in global coordinates (e.g., 0, 0, -1 for a downward load)
    5. Enter the magnitude

    To extract the normal (TRNOR) and shear (TRSHR) components of the traction after analysis, request these in Field Output — see Requesting Outputs.

    How do I apply a line load?

    A line load (force per unit length) can only be applied to free surface edges in Abaqus. For interior locations, convert it to an equivalent pressure over a narrow strip:

    1. Choose a strip width w and partition your geometry to create that strip
    2. Calculate the equivalent pressure: p = q / w
    3. where q is the line load (force/length) and w is the strip width
    4. Example: 12 lbf/in over a 2 in strip = 6 lbf/in²
    5. Apply this pressure to the partitioned strip face in the Load Module

    How do I apply a distributed moment?

    1. In the Load Module, go to Tools > Analytical Field > Create — name it, select Expression field, and enter your moment distribution expression
    2. In the Mesh Module, create a node set: Tools > Set > Create, select Node, select the target nodes
    3. Back in the Load Module, click Create Load > Mechanical > Moment
    4. Click Sets to choose your node set, then select your analytical field under Distribution
    5. Fill in the moment direction (CM1, CM2, or CM3) and click OK

    !!! note The moment is applied per node and has units of force × length. To verify, request CF in Field Output and check CM in the results.

    How do I verify the pressure I applied?

    1. In the Step Module, edit your Field Output request
    2. Under Loads, add P (pressure) to the selected outputs and click OK
    3. Run the job and open results in the Visualization Module
    4. Select PLOAD as the field variable to confirm the applied distribution

    My load arrows aren't changing when I update the magnitude — is something wrong?

    No — this is expected behavior in Abaqus/CAE. Load arrow sizes are uniform and unrelated to the prescribed magnitude. They are direction indicators only. The exception is when an analytical field is used, in which case arrow sizes scale with the field value.
